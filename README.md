# Crossy Lilka

Гра для консолі Lilka у стилі Frogger та Crossy Road. Курча перебігає смугу за смугою, ухиляється від машин, збирає монетки й біжить до фінішу. Усе вміщається приблизно в сотню рядків Lua.

## Як грати

- Стрілки — рух
- D — пауза
- B — вихід

Монетка дає +10 балів, фініш — +50 і наступний рівень. Життів три: зіткнення з машиною відкидає курча на старт.

## Запуск

Скопіюй теку гри разом із картинками в assets на Лілку й запусти crossy.lua через KeiraOS.

## Спрайти

Курча й машини — набір [Crossy Road 2D Sprites](https://thdudk.itch.io/crossy-road-2d-sprites), сердечко й монетка — з pngtree.com.
